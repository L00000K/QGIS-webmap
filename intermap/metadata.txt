changelog=
    1.9.0 - 3D view moved to the feature/3d branch; the plugin ships 2D only while the Cesium work continues out of the release line. Runs on QGIS 4 / Qt6 as well as QGIS 3 (fully-scoped enum members, exec() for exec_(), QAction and the layer/geometry type enums resolved through a compatibility module); Dialog reorganised into a Project tab (map profile + project config) and a final Export settings tab, with a live capability summary in the config ribbon; warns when QGIS is older than the last LTR; web map fixes: paged attribute table and debounced data-level filtering for large datasets, greyscale basemap option, measure tool drawn above the basemap, minimap toggle/close icons, legend and scale bar in printed output, blank bottom-left watermark box removed, permalink button removed; print tool moved into the map toolbar with a Map tools checkbox to include or omit it, and printed output now carries north arrow, title, scale/centre note and data credit; explode/spread now handles clusters of any practical size by wrapping tall stacks into extra columns instead of silently ignoring any group over 12 points; map views gain 'show in canvas' and 'copy from other map view' for both extents and layers; the Layers tab now tracks the QGIS project live instead of needing a restart after layers are added, removed or renamed; the help overlay now covers measure, print, data export, sketch, 2D/3D, map views, title block and changelog, and lays its callouts out so they never overlap; explode/spread proximity grouping rewritten to be linear, lifting the 400-marker limit that silently disabled it on any sizeable point layer; fixes dialog layout: Title block sections no longer stretch and bottom-align their text boxes when the sections below are collapsed, and the Map Views list stays at the top instead of sitting centred until a view is selected
    1.8.0 - Data-export button (download layers as GeoJSON/CSV); report mode gains a title-block+chapters sidebar, a PDF export button and a collapsible page-thumbnail strip; 3D hardened for token-free use and flat data (features draped/clamped to the globe, drawn over terrain)
    1.7.0 - Dialog rebuilt around a Setup tab: switch on Title block / Map views / Report / 3D and their tabs appear; retired the Lite/Pro/3D mode buttons (a simple map is just no capabilities); 3D and Report each get their own tab
    1.6.1 - Fix: dialog tabs now always scroll, so the Export/Close buttons can never be pushed off-screen on short docks or small displays
    1.6.0 - Line symbology fidelity: cased/multi-stroke lines (e.g. coloured core with a casing), marker/hashed 'tick' lines, and curved labels that follow the line via SVG textPath
    1.5.0 - PDF report mode: scroll a PDF beside the map with page-to-view bindings that fly the map as you read (self-contained via bundled PDF.js); dialog gains PDF picker and bindings table
    1.4.0 - Bottom-up rebuild: exporter split into a package with the web app as real HTML/CSS/JS template files; report mode fixed (embedded marked.js was corrupted by over-eager escaping); dead code removed; tests now exercise the real modules
    1.2.0 - Multi-feature click, attribute table, themes dropdown, zoom fix
    1.1.0 - Shape markers, labels, collision detection, groups, info panel, initial extent
    1.0.0 - Initial release
